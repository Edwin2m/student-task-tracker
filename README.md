# Student Task Tracker

A full-stack task management web application built with React, Express, and PostgreSQL.

## Features

- Create tasks
- View tasks
- Delete tasks
- Mark tasks complete/incomplete
- Filter completed tasks
- Responsive frontend
- REST API backend
- PostgreSQL database integration

## Tech Stack

Frontend:
- React
- Vite
- Axios

Backend:
- Node.js
- Express.js

Database:
- PostgreSQL

Deployment:
- Render
- Vercel
